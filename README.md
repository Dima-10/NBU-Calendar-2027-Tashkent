# НБУ · Культурное наследие Узбекистана — «История костюма», Бухара (Январь)

Одностраничный лендинг для перехода по QR-коду. HTML5 + CSS3 + vanilla JS, без фреймворков и сборки.

## Запуск
Любой статический хостинг по **HTTPS** (иначе браузеры строже блокируют автозапуск и звук).
Хостинг должен отдавать видео с поддержкой HTTP Range (почти все так делают).
Локально: `python3 -m http.server` не поддерживает Range — для проверки видео лучше любой другой сервер (например `npx serve`).

## Структура
```
index.html            разметка и весь текст (русский)
css/style.css         дизайн-токены (:root) и стили
js/main.js            воспроизведение/звук, сжатие видео при прокрутке; CONFIG вверху файла
assets/video/uzbek-costume.mp4   видео (сейчас — рабочая заглушка)
assets/images/poster.webp        постер (кадр до старта видео)
assets/images/logo-nbu-gold.svg  ЗАГЛУШКА логотипа — заменить официальным золотым логотипом
assets/fonts/inter-*.woff        Inter 400/500/600, кириллица + латиница
```

## Что заменить
1. **Видео**: перезапишите `assets/video/uzbek-costume.mp4` (H.264, `-movflags +faststart`, желательно 1080×1920, 8–12 Мбит/с макс.). Для бесшовной петли первый и последний кадры должны совпадать. Код менять не нужно. Постер: `poster.webp` (кадр из видео, ~720 px по ширине).
   Точка фокуса кадра на широких экранах: `data-focus-x` / `data-focus-y` у `<video>` (проценты).
2. **Логотип**: перезапишите `assets/images/logo-nbu-gold.svg` (логотип — на странице брендбука nbu.uz/ru/o-banke/firmennyy-stil). Золотой логотип по брендбуку ставится только на белый или светлый фон, поэтому на видео он не размещается.
3. **Тексты**: всё, что в `<span class="ph">…</span>`, — заглушки («После исследования»). Замените текст и удалите обёртку `ph`.
4. **Фото** (раздел «Ткани, орнаменты и детали»): замените `<div class="card__media">` на
   `<img src="assets/images/….jpg" alt="…" width="800" height="1000" loading="lazy" decoding="async">`.

## Поведение звука
1. Страница пробует запустить видео со звуком.
2. Если браузер запрещает (iOS Safari, часть Chrome на Android) — появляется экран «Нажмите, чтобы начать»; по нажатию видео стартует со звуком.
3. После старта — маленькая кнопка звука (в углу видео, следует за ним при уменьшении).
Тихий режим без уведомления не включается. Если в файле нет аудиодорожки, кнопка звука скрывается (`CONFIG.hideSoundControlIfSilent`).
Когда видео полностью прокручено, оно ставится на паузу и продолжается при возврате (`CONFIG.pauseWhenOffscreen`).

## Доступность и режимы
`prefers-reduced-motion`: без анимации сжатия — обычная вёрстка. Без JavaScript: видео с нативными кнопками управления и весь текст.

## Цвета (брендбук НБУ)
Синий `#274378`, золотой `#B88F5A`, дополнительный `#1FA9C5`. Производные (фоны, цвет текста, тёмное золото `#8A6A3B` для мелкого текста) помечены в CSS как производные.

## Подсказка «Прокрутите вниз»
Элемент `#scroll-hint` (текст + один SVG-шеврон) на первом экране поверх видео.
- Появляется через 3 с после события `playing` у видео (`HINT_DELAY` в `js/main.js`), только пока страница в самом верху.
- Исчезает сразу при начале прокрутки, паузе или ошибке видео; при открытом экране «Нажмите, чтобы начать» не показывается.
- При возврате в самый верх появляется снова через 3 с, если видео играет. Таймер всегда один (`hintTimer`).
- `prefers-reduced-motion: reduce` — шеврон не анимируется. Анимация: `@keyframes scroll-hint-bounce` в `css/style.css`.
